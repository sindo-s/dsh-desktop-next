# 0.4.0-alpha.5 · 在线手动安装测试版

本次只发布 Windows x64 在线安装包。不包含 Ubuntu 镜像、WSL 离线安装器或用户数据；首次准备环境需要联网。
不发布 latest.json，不开启自动更新。此版本不是经过全新 Windows 虚拟机验证的稳定版。

## 安装

下载名称以 x64-online.exe 结尾的安装包，安装后在“安装与环境”准备 WSL 和内核。
首次启用 WSL 可能需要管理员授权、硬件虚拟化和重启。
签名附件用于发布完整性验证，不是 Windows Authenticode 签名；可能出现 SmartScreen 未知发布者提示。

## 已使用旧 alpha 版本的用户

应用标识已改变，Windows 侧管理设置不会自动迁移。不要把本版视为无缝覆盖升级。
先备份旧配置与重要项目，关闭旧桌面窗口；不要删除或注销旧 WSL 发行版。
本版仍使用正式发行版 DSH-Desktop-Next，不是与日常会话隔离的试用版。
已有 WSL 会话不会因桌面安装而自动复制或清空，但安装升级、卸载及配置迁移尚未完成独立系统验证。
不愿承担试用风险的旧用户请保留原版本。

## 本次变化

- 移除个人用户名的应用标识。
- MIT 许可证与第三方许可材料。
- 开发版独立配置和 WSL，发布材料只从已提交源码准备。
- 保留单窗口聊天、官方内核管理、插件管理和回滚能力。

官方内核通过 npm 下载，不固定为离线镜像中的版本；其兼容性随官方发布而变化。
